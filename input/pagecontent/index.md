# AI Transparency on FHIR -- Connectathon 43 Test Data

Synthetic FHIR R4 test data for the AI Transparency on FHIR track, built to exercise
the track's testing scenarios and conform to the [AI Transparency on FHIR IG](https://build.fhir.org/ig/HL7/aitransparency-ig/en/).

All patient data is originally generated by [Synthea](https://github.com/synthetichealth/synthea)
(Massachusetts population); no real patient data is used. Clinical codes and values
were never altered by hand -- only resource selection, reference repair, ID rewriting,
AI security labels, AI Provenance, and the two hand-authored clinical notes were added.

More details and regeneration instructions at [Sam Shifman GitHub](https://github.com/samschifman/ai-trans-on-fhir-connectathon-43).
